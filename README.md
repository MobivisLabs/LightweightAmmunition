![Details](/About/Banner_Details.png)

Resources used as ammunition can become a major **Mass limitation**, especially with vehicle mods that have limited storage capacity.

This mod adds lightweight ammunition made from commonly used raw resources, giving you more ammunition without the heavy **Mass** of carrying the raw resources.

**Pure XML.** No assemblies, ticking, Harmony patches, unnecessary systems, or bloat.

**TL;DR:** Lightweight ammunition for vehicle mods & turrets, letting you carry more ammo without worrying about not enough storage space.

![FAQ](/About/Banner_FAQ.png)

**Q:** Why do you make this?

**A:** Because I want something to able to carry a lot of ammunition for my Vehicles.

**Q:** Why you patch turrets too?

**A:** Because I find it fitting to have it use it more, since it has more ammo coverted than raw resources itself.

**Q:** Does this effect projectile?

**A:** No, you can replace with anything. The turret would fire their own projectile def regardless.

**Q:** Why did you not patch Turrets that comsumed Reinforce Barrel?

**A:** Balance reason.

**Q:** Performance?

**A:** No performance loss. Pure XML — no Harmony assemblies, no tickers.

**Q:** I want Patch support for this certain **MOD**

**A:** Either with or without using XmlExtensions or directly create your own PatchOperationReplace with the ThingDefs ammunition.

**Q:** Can I disabled certain turrets patch?

**A:** Install XmlExtensions.
